# Current design

FINN uses a black/charcoal and warm-gold palette, Inter Tight headings, Inter body text, an original geometric F monogram and subtle ambient motion that respects reduced-motion preferences.

The user-selected visual reference was Golden Suisse:
https://dribbble.com/shots/26164822-Golden-Suisse-App-Design-UX-UI

The implemented product has its own investor briefing, evidence-linked research, financial scorecard and conversation interactions. Earlier cream/green experiments are not the submitted design.

Responsive layouts, safe areas, readable phone forms and wrapped source controls support a mobile-first responsive-web submission.
